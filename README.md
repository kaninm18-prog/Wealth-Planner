# Wealth Planner

Investments and assets for one person: holdings, live prices, allocation and targets, returns against an index,
dividends and a trading journal. It works alongside [Money Tracker](https://github.com/kaninm18-prog/money-tracker),
which stays the cashflow app. Plain HTML/JS front end on GitHub Pages; Google Apps Script + Google Sheets back end.

Start with `CLAUDE.md`. To run the checks, use `npm ci` and then `npm run check`.
